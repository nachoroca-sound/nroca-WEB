# Nacho Roca — Portfolio

Static EN-only portfolio for sound designer Nacho Roca. No Node/npm required. Generated by a small Python build script, deployed on Netlify.

## Site structure

- `index.html` — homepage (hero + featured projects grid). **Generated** by `build.py`.
- `games.html` — video games grid. **Generated**.
- `film.html` — film & advertising grid. **Generated**.
- `about.html` — bio, manifesto, CV download. **Generated**.
- `contact.html` — mailto link + Google Maps embed. **Generated**.
- `demos.html` — hidden demos page (noindex). **Generated**.
- `projects/<id>.html` — one page per project with Vimeo embed, meta table, and prev/next nav. **Generated**.
- `privacy.html` — GDPR privacy policy. Hand-written (not generated).
- `404.html` — error page. Hand-written (not generated).
- `data/content.json` — all site copy (nav, hero, about, contact, footer) in EN.
- `data/projects.json` — all project entries (videogames, advertising, demos).
- `templates/*.html.tmpl` — HTML skeletons that `build.py` fills in with `{{TOKEN}}` substitution.
- `css/style.css`, `js/main.js` — shared by every page.

## Editing content

1. Edit `data/content.json` (site text) and/or `data/projects.json` (projects).
2. Run:
   ```
   python3 build.py
   ```
3. Commit and push — Netlify picks up the changes automatically.

**Never edit generated `.html` files by hand** — your changes will be overwritten on the next build. Edit the template or data source instead.

## Adding a project

1. Add an entry to the relevant array in `data/projects.json` (`videogames`, `advertising`, or `demos`).
2. Required fields: `id`, `slug`, `title.en`, `description.en`, `previewVideo`, `vimeoId`.
3. For hash-protected Vimeo videos, also add `vimeoHash`.
4. For a second Vimeo player on the same page, add `vimeoId2` (and `vimeoHash2` if needed).
5. Run `python3 build.py`.

To get a project's `vimeoId`: open the video on vimeo.com, copy the number from the URL (`vimeo.com/123456789`).

| File | Weight | Usage |
|---|---|---|
| `AvenirNextCondensed-Black.woff2` | 900 | Headings, nav, titles |
| `AvenirNext-Medium.woff2` | 500 | Body, captions, labels |

## Deploying

Static site — no build step at deploy time. Run `python3 build.py` locally, commit everything, and push. Netlify deploys from the repo root (`publish = "."`).

`_headers` sets the Content Security Policy. `netlify.toml` sets long-lived cache headers for assets.
